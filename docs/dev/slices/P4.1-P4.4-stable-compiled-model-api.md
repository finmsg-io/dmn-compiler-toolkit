## Outcome

A thread-safe, modern **Protobuf-native** compiled-model evaluation API (`DmnCompiledModel`) hides internal integer slot numbers and Runtime IR IDs, exposing name-based evaluation capabilities backed by binary Protobuf schemas (`evaluation.proto`).

## In scope

- Protobuf schema `evaluation.proto` defining `Value`, `ListValue`, `ContextValue`, `RangeValue`, `EvaluationRequest`, `EvaluationResponse`, `EvaluationDiagnostic`, and `CompiledModelMetadata`.
- Name-based input binding and name-based decision result querying.
- Support for requested decision pruning (evaluating requested decision sub-graphs rather than full models).
- Immutable, thread-safe `DmnCompiledModel` facade exposed on `DmnCompilationResult`.
- Both native Protobuf API calls (`evaluate(EvaluationRequest)`) and ergonomic Java Map bindings (`evaluate(Map<String, Object>)`).

## Non-goals

- Native Java bytecode generation (deferred to P5).
- Standalone gRPC service daemon (deferred to P7).

## Architectural constraints

- Public API callers must never need internal slot integers or internal DRG IDs.
- Evaluation must be immutable, thread-safe, and side-effect-free across concurrent threads.
- High-precision numeric values must be preserved without binary floating-point precision loss.
