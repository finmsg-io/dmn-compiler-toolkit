### P6.2 — Complete Decision Table Hit Policy Support
Implement and lower all DMN 1.5 specification decision table hit policies:
- `UNIQUE` (U) — exactly one rule must match.
- `FIRST` (F) — return the output of the first matching rule.
- `PRIORITY` (P) — return output matching highest priority in output allowed values.
- `ANY` (A) — all matching rules must yield the exact same output.
- `COLLECT` (C) — accumulate outputs:
  - `COLLECT` (List of outputs)
  - `COLLECT +` (Sum of outputs)
  - `COLLECT *` (Product of outputs)
  - `COLLECT <` (Min output)
  - `COLLECT >` (Max output)
  - `COLLECT #` (Count of matching rules)
- `RULE ORDER` (R) — return list of outputs ordered by rule sequence.
- `OUTPUT ORDER` (O) — return list of outputs ordered by output allowed values.
