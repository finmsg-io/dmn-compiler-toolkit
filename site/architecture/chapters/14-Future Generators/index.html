    Chapter 14 --- Future Generators [FUTURE]¶

    14.1 Purpose¶

    The DMN Compiler Toolkit is designed as a multi-backend compiler platform.

    The primary architectural goal is that all future targets consume the same optimized Runtime IR.

    A new backend must not require:

    • changes to XML parsing
    • changes to FEEL parsing
    • changes to semantic analysis
    • changes to optimization passes

    The architecture:

                             Runtime IR

                              |

          +-------------------+-------------------+
          |                   |                   |
          v                   v                   v

        Java                Rust              Spark SQL

          |                   |                   |

          v                   v                   v

       JVM App             Native App        Databricks

    14.2 Backend Design Principle¶

    14.4 Generator SPI¶

    All generators implement the same interface.

    Example:

    public interface CodeGenerator {

    String target();

    GeneratedArtifact generate(
        RuntimeModel model
    );

}

    Example:

    Java:

    public class JavaGenerator
implements CodeGenerator {

    public String target(){

        return "java";

    }

}

    Rust:

    public class RustGenerator
implements CodeGenerator {

    public String target(){

        return "rust";

    }

}

    14.6 Rust Generator¶

    Purpose¶

    Generate native high-performance decision engines.

    Architecture:

    Runtime IR

     |

     v

Rust Generator

     |

     v

Rust Source

     |

     v

Native Binary

    Generated example:

    Runtime IR:

    LOAD speed

LOAD 100

COMPARE_GT

    Rust:

    pub fn evaluate(
    input: &TrafficInput
)
-> Penalty {

    if input.speed > 100 {

        Penalty::High

    }
    else {

        Penalty::Low

    }

}

    Advantages:

    • native execution
    • low latency
    • no JVM
    • embedded systems
    • WASM compatibility

    14.8 Spark SQL Generator¶

    Purpose¶

    Generate distributed decision execution.

    Architecture:

    Runtime IR

      |

      v

Spark SQL Generator

      |

      v

SQL Expression

      |

      v

Spark Execution Engine

    Example:

    DMN:

    if amount > 1000
then "HIGH"
else "LOW"

    Generated:

    CASE

WHEN amount > 1000

THEN 'HIGH'

ELSE 'LOW'

END

    Advantages:

    • massive data processing
    • Databricks integration
    • no row-by-row interpretation
