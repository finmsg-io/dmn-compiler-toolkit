    Chapter 17 --- Public API [FUTURE]¶

    17.1 Purpose¶

    The Public API defines the stable integration boundary between users and the DMN Compiler Toolkit.

    The architecture separates:

    • internal compiler implementation
    • public developer-facing interfaces

    Users should not need to understand:

    • XML parsing
    • FEEL parsing
    • compiler passes
    • optimization
    • Runtime IR internals

    The public API provides a simple abstraction:

    DMN Model

     |

     v

Compiler API

     |

     v

Executable Decision Model

    17.2 API Design Principles¶

    API-001 --- Simple Entry Point¶

    The common use case should require minimal code.

    Example:

    Compiler compiler =
    Compiler.builder()
            .build();

DecisionModel model =
    compiler.compile(
        Path.of("traffic.dmn")
    );

    API-002 --- Hide Compiler Internals¶

    Application code should never directly access:

    XmlReader

FeelParser

SemanticAnalyzer

Optimizer

RuntimeBuilder

    Instead:

    Compiler

    is the facade.

    API-003 --- Stable Contracts¶

    Public interfaces evolve slowly.

    Internal modules may change:

    VTD-XML

↓

different XML parser

    without affecting users.

    17.3 Public API Modules¶

    Recommended module:

    dmn-api

    Dependencies:

    dmn-runtime-api

dmn-model-api

    The API module must NOT depend on:

    antlr

vtd-xml

compiler passes

    Package:

    io.finmsg.dmn.api

    Structure:

    api

├── Compiler

├── CompilerConfiguration

├── CompilationResult

├── DecisionModel

├── DecisionExecutor

├── Diagnostic

├── Backend

└── Version

    17.4 Compiler API¶

    Main entry point:

    public interface Compiler {

    CompilationResult compile(
        Source source
    );

}

    Example:

    CompilationResult result =
    compiler.compile(
        Source.file(
            "traffic.dmn"
        )
    );

    17.5 Compiler Builder¶

    Configuration is explicit.

    Example:

    Compiler compiler =
    Compiler.builder()

        .backend(
            Backend.JAVA
        )

        .optimization(
            OptimizationLevel.MAX
        )

        .build();

    Possible options:

    backend

optimization level

diagnostic mode

cache

security limits

source mapping

    17.6 Compilation Result¶

    Compilation returns a structured result.

    Example:

    public interface CompilationResult {

    boolean successful();

    DecisionModel model();

    List<Diagnostic> diagnostics();

}

    Usage:

    if(result.successful()) {

    DecisionModel model =
        result.model();

}

    17.7 Diagnostics API¶

    Compiler errors are first-class objects.

    Example:

    public record Diagnostic(

    Severity severity,

    String code,

    String message,

    SourceLocation location

){}

    Example result:

    ERROR DMN-2004

Unknown variable:

speedLimit

traffic.dmn

line 25

    17.8 Decision Model API¶

    The compiled decision model represents executable output.

    Example:

    public interface DecisionModel {

    String name();

    DecisionExecutor executor();

}

    The application does not know whether the model came from:

    Java generation

Bytecode

Interpreter

Native backend

    17.9 Decision Execution API¶

    Runtime API:

    public interface DecisionExecutor {

    DecisionResult execute(
        DecisionInput input
    );

}

    Example:

    DecisionResult result =
    executor.execute(
        input
    );

    17.10 Input API¶

    Two supported modes.

    Generic Input¶

    Flexible:

    DecisionInput input =
    DecisionInput.builder()

        .put(
            "speed",
            120
        )

        .build();

    Generated Input¶

    High-performance:

    TrafficInput input =
    new TrafficInput(
        120
    );

    17.11 Result API¶

    Example:

    public interface DecisionResult {

    Object value();

    Map<String,Object> outputs();

}

    Example:

    Penalty penalty =
    result.value();

    17.12 Backend Selection¶

    The API supports multiple targets.

    Example:

    Compiler compiler =
    Compiler.builder()

        .backend(
            Backend.RUST
        )

        .build();

    Available:

    JAVA

RUST

GO

SPARK_SQL

WASM

    17.13 Compilation Pipeline API¶

    Advanced users may access pipeline stages.

    Example:

    CompilerPipeline pipeline =
    PipelineBuilder.create()

        .xmlFrontend()

        .feelParser()

        .optimizer()

        .runtimeBuilder()

        .build();

    This API is considered advanced.

    17.14 Streaming Compilation API¶

    For large environments:

    Example:

    compiler.compile(
    InputStream stream
);

    Benefits:

    • lower memory
    • CI/CD integration
    • repository scanning

    17.15 Incremental Compilation API¶

    Large repositories require incremental builds.

    Example:

    CompilationCache cache =
    new CompilationCache();

compiler.compileIncremental(
    source,
    cache
);

    Only changed artifacts are rebuilt.

    17.16 Maven Plugin API¶

    The compiler integrates into builds.

    Example:

    <plugin>

    <groupId>
        io.finmsg.dmn
    </groupId>

    <artifactId>
        dmn-maven-plugin
    </artifactId>

</plugin>

    Build:

    mvn compile

    Pipeline:

    DMN Files

    v

    17.17 CLI API¶

    Command-line access:

    Example:

    --backend java

--optimize max

--output target/generated

--diagnostics verbose

    dmn inspect traffic.dmn

    Decisions:

    17.19 Versioning Strategy¶

    Public API follows semantic versioning.

    Example:

    1.0.0

    Major

breaking changes

    17.20 API Compatibility Rules¶

    Allowed:

    Add new methods

Add new backends

Add new diagnostics

    Breaking:

    Remove interfaces

Change method signatures

Change result semantics

    17.21 Example Complete Application¶

    Application code:

    public class Application {

public static void main(
    String[] args
){

Compiler compiler =
    Compiler.builder()
            .build();

DecisionModel model =
    compiler.compile(
        Path.of(
            "traffic.dmn"
        )
    )
    .model();

DecisionResult result =
    model.executor()
         .execute(
             input
         );

System.out.println(
    result.value()
);

}

}

    17.22 Public API Summary¶

    The public API provides:

    • simple compiler entry point
    • stable integration boundary
    • backend independence
    • structured diagnostics
    • runtime execution abstraction
    • Maven integration
    • CLI support
    • future IDE integration

    The user sees:

    DMN File

   |

   v

Compiler API

   |

   v

Decision Result

    The internal compiler remains free to evolve.
